
# Low-Power ALU Design Using Operand Isolation Technique

## Project Overview
This project implements a 4-bit Arithmetic Logic Unit (ALU)
using the Operand Isolation Technique to reduce unnecessary
switching activity in inactive functional units.

## Operations
- Addition
- Subtraction
- Bitwise AND
- Bitwise OR

## Tools Used
- EDA Playground
- SystemVerilog
- Icarus Verilog
- EPWave

## Project Structure
- Normal_ALU
- Low_Power_ALU

## Working Principle
The Normal ALU performs all four operations.
The Low-Power ALU uses operand isolation to prevent
unnecessary input transitions in inactive functional units.
